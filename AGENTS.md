# Repository guidance

Use the [AxolotlBucketLabs skill](https://github.com/AxolotlBucketLabs/axolotl-bucket-labs/blob/main/SKILL.md) for this Axolotl-PM virion. Read its [writing style](https://github.com/AxolotlBucketLabs/axolotl-bucket-labs/blob/main/references/writing-style.md) before writing human-facing prose.

Follow the skill's technical guidance and organization policy for this repository. Preserve the existing public package name, namespace, and license unless a task explicitly changes them.

Write natural, complete sentences. Do not use em dash or en dash punctuation or semicolons in prose. Avoid unnecessary label-shaped sentences. Use straight double quotes and Markdown inline code for technical names and paths.
